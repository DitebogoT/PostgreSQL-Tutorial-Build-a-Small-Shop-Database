Tutorial 10 – Final review challenge
Time: 20 minutes

You have now created a small relational database for BrightMart. Complete this challenge without copying the earlier queries directly.

Business request
The shop manager wants a short report about customers, products and orders.

Write SQL queries that answer the following questions:

Display all customers, showing their first name, last name and email.
Display all products sorted from cheapest to most expensive.
Find products with fewer than 20 units in stock.
Display each order with the customer's name and order status.
Display each order's products, quantities and unit prices.
Calculate the total value of each order.
Calculate the average price of all products.
Find the five most expensive products.
Count how many customers are registered.
Add a new customer and create an order for that customer.
